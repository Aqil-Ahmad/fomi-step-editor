# Fomi Step Editor

An image editing workspace where every AI edit is a step you can adjust, locks protect brand details, and one look can be applied to a whole shoot.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` starts the dev server
- `npm run build` creates a production build
- `npm run lint` runs ESLint

## Branches

- `main` is production
- `dev` is where feature branches are merged
